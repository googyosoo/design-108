# DesignMind 108 — 사용자 종합 매뉴얼 (User Guide)

> **DesignMind 108**은 학교 교실, 교원 직무 연수, 교육용 웹앱, 학부모 안내 자료를 만드는 모든 교육자와 제작자를 위한 인터랙티브 시각 심리학 플랫폼입니다.

---

## 1. 대상별 활용 워크플로우

### 1) 교사용 활용법 (For Teachers)
- **수업 활용 허브 (`/teach`)**:
  - 고등학교 영어과, 정보 미디어 리터러시, 도서관 북큐레이션, 교원 직무 연수 등 4종 모듈 제공.
  - 차시별 교수·학습 과정안과 평가 루브릭을 확인하세요.
  - [활동지 A4 인쇄하기] 버튼을 누르면 학생 배포용 활동지가 A4 규격에 맞춰 여백 없이 깨끗하게 인쇄됩니다.
- **원리 발표 모드 (`/effect/:code/present`)**:
  - 전자칠판 및 프로젝터 대화면 전용 슬라이드 덱입니다.
  - 키보드 방향키(`←`/`→`)와 스페이스바로 슬라이드를 넘기고, `F` 키로 전체화면을 켭니다.
  - 슬라이드 3번에서 학생들과 30초 대화형 인터랙티브 실험실을 실시간으로 함께 시연하세요.
- **AI 프롬프트 빌더 (`/tools/builder`)**:
  - 가정통신문이나 슬라이드를 만들 때, 대상 매체와 목적을 고르면 108 원리가 반영된 AI 지시문(Markdown)이 3초 만에 생성됩니다.

---

### 2) 학생용 활용법 (For Students)
- **원리 도감 탐색 (`/library`)**:
  - 초성 검색(예: `ㅍㅊ` -> 피츠의 법칙)으로 원하는 원리를 빠르게 찾으세요.
  - 카테고리 칩(가독성, 신뢰감, 빠른 탐색 등)으로 필요한 심리 효과를 필터링할 수 있습니다.
- **연습 허브 (`/practice`)**:
  - **4지선다 상황형 퀴즈**: 학교 생활 속 40가지 디자인 딜레마를 10문제씩 풀어보세요.
  - **윤리 & 다크패턴 판별기**: 사용자를 돕는 착한 넛지와 속임수 다크패턴을 판별하는 눈을 기릅니다.
  - **108 플래시카드**: 카드를 탭하여 원리 영단어와 한국어 개념을 복습하세요.
- **마이페이지 (`/my`)**:
  - 내가 학습한 원리 개수, 챕터별 게이지, 퀴즈 점수 기록을 확인하고 JSON 파일로 안전하게 백업하세요.

---

### 3) 기획자 / 디자이너 활용법 (For Designers & Creators)
- **AI 디자인 진단 스튜디오 (`/tools/diagnose`)**:
  - 제작 중인 시안 캡처 이미지를 드래그하여 올리면, 15초 안에 시선 유도, 명도 대비, 정보 밀도를 분석하여 3대 개선 처방전을 제공합니다.
- **WCAG 2.2 명도 대비율 측정 (`/effect/012` 등)**:
  - 텍스트 색상과 배경색을 선택하면 AA(4.5:1) 및 AAA(7.0:1) 적합 여부와 적색맹/녹색맹/청색맹 시뮬레이션을 실시간 검증합니다.
- **실전 리메이크 스튜디오 (`/cases`)**:
  - 11편의 비포/애프터 분할 슬라이더를 밀어보며 인터랙티브 핫스팟(Hotspot) 핀을 클릭해 적용 원리를 역설계(Reverse Engineering)해 보세요.

## 2. 전역 단축키 가이드 (Hotkeys)

| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Ctrl + K`** / **`Cmd + K`** | 전역 초성/퍼지 검색 모달창 열기 |
| **`X`** (알파벳 X) | **X-ray 인지 모드** 토글 (현재 화면에 적용된 심리 원리 오버레이) |
| **`F`** / **`f`** | 발표 모드 전체화면(Fullscreen) 토글 |
| **`←`** / **`→`** / **`Space`** | 발표 모드 이전 / 다음 슬라이드 이동 |
| **`Esc`** | 발표 모드 종료 및 검색창 닫기 |

---

## 3. 데이터 및 개인정보 안전성
- **No Login / No Database**: 회원가입 없이 즉시 사용 가능합니다.
- **Local Storage Only**: 북마크, 학습 진도, 퀴즈 결과는 오직 내 브라우저에만 저장되며 외부 서버로 전송되지 않습니다.
- **PWA 오프라인 지원**: 홈 화면에 앱으로 설치하여 인터넷이 연결되지 않은 교실에서도 오프라인으로 원리를 열람할 수 있습니다.
